១. ឈ្មោះទូទៅ និងពេញនិយមបំផុត (Industry Standard Terms)

និយមន័យស្តង់ដារអន្តរជាតិសម្រាប់ប្រព័ន្ធគ្រប់គ្រងការលក់ និងប្រតិបត្តិការ

POS System (Point of Sale System)

ជាប្រព័ន្ធបច្ចេកវិទ្យាសម្រាប់គ្រប់គ្រងប្រតិបត្តិការលក់ គិតប្រាក់ ស្កេនទំនិញ បញ្ជាទិញ (Order) និងចេញវិក្កយបត្រ (Receipts) នៅកន្លែងគិតប្រាក់ដោយផ្ទាល់ ជាមួយភាពរហ័សរហួន និងត្រឹមត្រូវខ្ពស់។

Cashier Terminal KHQR / ABA Scan Barcode Scanner

All-in-One Management System

ជាប្រព័ន្ធគ្រប់គ្រងអាជីវកម្មពេញលេញ End-to-End ដែលតភ្ជាប់គ្រប់ផ្នែកក្នុងស្ថាប័នតែមួយ៖ ចាប់តាំងពីការកុម្ម៉ង់ ផ្ញើទៅផ្ទះបាយ/បារ (KDS), គ្រប់គ្រងតុ, ឃ្លាំងស្តុក (Inventory), បុគ្គលិក រហូតដល់របាយការណ៍វិភាគហិរញ្ញវត្ថុ។

Section 02

២. ឈ្មោះបែងចែកតាមប្រភេទអាជីវកម្ម (Business-Specific)

ការអនុវត្តផ្ទាល់ទៅលើទីផ្សារអាជីវកម្ម Sky Bar / F&B និង Retail Market

Food & Beverage Solution 🍸 🍽️

F&B POS / RMS (Restaurant Management System)

សម្រាប់៖ Sky Bar, Pub, Lounge, Club, Restaurant, Cafe
  • ✓ Table & Floor Management: បែងចែកតំបន់តុ VIP, Rooftop, Sofa, Bar Counter និងតាមដាន Live Status។
  • ✓ Modifiers & Add-ons: កំណត់កម្រិតជាតិស្ករ ទឹកកក ជាតិអាល់កុល (Cocktail Mixers, Shot/Bottle)។
  • ✓ Live Kitchen & Bar KDS: អេក្រង់ចុងភៅ និង Bartender ទទួល Order ភ្លាមៗតាម WebSocket។
  • ✓ Split Bill & Open Tab: ងាយស្រួលបំបែកវិក្កយបត្រ ឬផ្ទេរតុពេលភ្ញៀវប្តូរទីតាំង។
Retail & Store Solution 🛒 📦

Retail POS System (Store Management)

សម្រាប់៖ Market, Mini-mart, Grocery, Supermarket, Retail Shops
  • ✓ Fast Barcode Checkout: ស្កេនបាកូដលឿនរហ័ស បញ្ចូលទំនិញចូលកន្ត្រក និងគិតប្រាក់ភ្លាមៗ។
  • ✓ Stock & Inventory Auto-deduct: កាត់ស្តុកទំនិញស្វ័យប្រវត្តិពេលលក់ និងមានប្រព័ន្ធ Alert ពេលស្តុកជិតអស់។
  • ✓ Category & Barcode Printing: ចាត់ថ្នាក់ទំនិញរាប់ពាន់មុខ និងបោះពុម្ពបាកូដវិក្កយបត្រ។
  • ✓ Multi-Payment Methods: ទូទាត់សាច់ប្រាក់, ABA KHQR, Credit Card ជាមួយការបញ្ចុះតម្លៃ (Discount)។

៣. ឈ្មោះតាមលក្ខណៈបច្ចេកវិទ្យា (Technical Architecture)

ស្ថាបត្យកម្មកម្រិតខ្ពស់ដែលធ្វើឱ្យប្រព័ន្ធមានល្បឿនលឿន និងសុវត្ថិភាពខ្ពស់

Go

Real-time Web POS

ប្រើប្រាស់ Golang Backend ផ្ដល់នូវល្បឿនប្រតិបត្តិការកម្រិត Microseconds និង WebSocket ធ្វើឱ្យគ្រប់ឧបករណ៍ (POS, Tablet, KDS) Sync ទិន្នន័យភ្លាមៗដោយមិនបាច់ Refresh ទំព័រ។

⚡ Ultra Low Latency Sync

Cloud POS / SaaS-Ready

ប្រព័ន្ធត្រូវបានបង្កើតឡើងតាមទម្រង់ Cloud SaaS ដែលអាចដាក់លក់ជាកញ្ចប់សេវាកម្មប្រចាំខែ/ឆ្នាំ (Subscription) គាំទ្រសាខាច្រើន (Multi-Branch) និងគ្រប់គ្រងពីចម្ងាយបានគ្រប់ពេលវេលា។

☁️ Multi-Tenant & Subscription Ready

Omnichannel / PWA

គាំទ្របច្ចេកវិទ្យា PWA (Progressive Web App) ដំណើរការបានរលូនលើគ្រប់ឧបករណ៍៖ POS Touchscreen, iPad, Android Tablet, Laptop និងទូរស័ព្ទដៃ ដោយមិនចាំបាច់ Install App ស្មុគស្មាញ។

5. Order Tracking
